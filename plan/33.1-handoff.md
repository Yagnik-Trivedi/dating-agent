## 6. Environment gotchas (this machine, Windows)

- **NVIDIA key:** `MODEL_MID` (Super) returns 404 → the LLM client falls back to Ultra (`MODEL_SMART`) for mid calls automatically (~23 s per agent turn).
- **Local checks:** `npm run dev-db` (replica set on :27999), then override the DB: `MONGODB_URI="mongodb://127.0.0.1:27999/dating_agent?replicaSet=testset"`. `server/.env` points at **Atlas (production)**.
- **api-check:** start the server with that URI and `LLM_ENABLED=false`, then `node scripts/api-check.js` with the same URI.
- **Client build:** needs `VITE_API_URL=http://localhost:5000 npm run build`. Local preview (`npx vite preview --port 4173`) also needs the server's `CLIENT_URL` to include `http://localhost:4173` (CORS).
- **Stop a local server before scripts that run their own worker** (simulate, eval): both would claim the same jobs.
- **Editing files:** bash heredocs with JS template strings sometimes break in this shell, and Python on Windows writes CRLF unless `newline='\n'`. Prefer the Edit/Write tools.
- **Circular imports:** `judge.js` ↔ `sessionJudge.js` and `scheduler.js` ↔ `sessionFlow.js` import each other. Never use the other module's exports at module top level (see `schemaOf()` in `sessionJudge.js`).
