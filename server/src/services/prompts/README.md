# Prompts

One file per prompt. Each exports `build(params) → messages[]`, which goes to `llm/client.js` (`chat` or `chatJSON`).
Prompt text lives here only, never inline in business logic. Every JSON output is validated with zod by the caller.

| File | Purpose | Tier | Output schema | Caller |
|---|---|---|---|---|
| `extractStoryFacts.js` | One free-text answer → facts about its author with verbatim quotes + concept text/type, polarity, strength, isCurrent, sensitive topic; plus a 1-line story summary | mid, reasoning off | `{ summary, facts: [{ predicate, object, conceptText, conceptType, polarity, strength, isCurrent, sensitiveTopic, quote }] }` (max 8; non-verbatim dropped) | `kg/extractFacts.js` (onboarding stories, inbox answers) |
| `describeStyle.js` | How the user texts, from their voice samples + computed metrics (secondary to real examples) | mid, reasoning off | `{ description, doList: [], dontList: [] }` | `kg/buildUserGraph.js` |
| `profileConsistency.js` | Declared tags vs free text contradictions + scam-script patterns in a profile (dealbreakers excluded: private) | mid | `{ contradictions: [{ a, b (verbatim quote), topic, severity 1–3 }], scamSignals: [{ signal, quote }], genericBio, summary }` (non-verbatim quotes dropped) | `trust/checkProfile.js` |
| `matchBrief.js` | Who the match seems to be (their PUBLIC profile only), 3 openers in the user's voice; anything about the user must cite listed fact ids | mid, reasoning off | `{ summary, openers: [{ text, hook, factIds }], watchouts: [] }` (> 2 sentences, unknown ids or uncited "I/my" dropped) | `brief/buildBrief.js` |
| `agentReply.js` | The next message(s) AS the user under the act plan (length, question, emoji, laugh, language, reactions, must-disagree, topic, end): my sampled facts + stories, private guidance (never raw), trait rules, my own exemplars, notes about them, anti-sycophancy rules | mid (or `AGENT_MODEL_BY_SIDE`), reasoning off, per-side sampled temperature | `{ messages: [], claims: [{ text, factIds, stance }], aboutThem: [{ text, sourceIds }], unknownAboutMe, end }` (claims verified in code: `persona/checks.js`) | `conversation/generate.js` |
| `alignment.js` | Batched: for each (user fact, closest match fact) pair → aligned / neutral / conflicting | fast | `{ pairs: [{ id, alignment }] }` | `compat/evaluate.js` |
| `verdict.js` | The judge: chemistry, reasons + concerns citing message ids, ask-yourself questions, summary (ONE call per viewer) | smart | `{ chemistry, reasons: [{ text, messageIds }], concerns: [...], askYourself: [], summary }` (items without a real message id are dropped) | `compat/evaluate.js` |
| `icebreakers.js` | 3 conversation starters for after the handoff, using the match's name | fast | `{ icebreakers: [] }` | `compat/evaluate.js` |
| `windDown.js` | One kind closing message in the user's style (incompatible verdict or Pass) | fast | `{ reply }` (fixed line if it has a question or a risky phrase) | `compat/index.js` |
| `dateIdeas.js` | Tavily results → 3 first-date ideas tied to shared interests | fast | `{ ideas: [{ title, why, link }] }` (links not in the results are dropped) | `tavily/dateIdeas.js` |
| `generatePersona.js` | Offline only: the voice of a seed persona whose values, interests and dealbreakers are fixed in code (bio, prompts, stories, texting samples, Big Five sketch); variants for mild inconsistency, thin and scam profiles | mid, reasoning off | `{ bio, prompts, stories, samples, personality }` | `scripts/generate-personas.js` |
| `factSupported.js` | Support check: does the answer really state each extracted fact (polarity + strength too)? | mid, reasoning off, t=0 | `{ results: [{ i, supported: yes\|no\|unclear }] }` (no → dropped, unclear → 0.6, yes → 0.9) | `kg/extractFacts.js` |
| `sameConcept.js` | Concept tie-break: is this phrase the same thing as one of ≤ 3 candidate concepts? | mid, reasoning off, t=0 | `{ same, conceptId }` | `kg/canonicalize.js` |
| `findContradictions.js` | B lifestyle answers (smoking/drinking/diet) vs story facts, one batched call per build | mid, reasoning off, t=0 | `{ contradictions: [{ attribute, fact, why }] }` (kept only if the story mentions alcohol/smoking/non-veg food) | `kg/buildUserGraph.js` |
| `tagLanguage.js` | Languages + script + code-switching per voice sample (any mix; `hi_latn` = romanised Hindi) | mid, reasoning off, t=0 | `{ tags: [{ i, languages, script, codeSwitch }] }` (code heuristics as fallback) | `kg/buildUserGraph.js` |
| `voiceCorrection.js` | A user's correction of how their agent texts → one rule | mid, reasoning off | `{ rule, kind: style\|never_say\|fact }` | `routes/kg.js` |
| `reflect.js` | 3–5 insights connecting ≥ 2 of the user's own facts (cited ids) | mid, reasoning off | `{ insights: [{ text, supportingFactIds }] }` | `kg/learning.js` |
| `perceive.js` | perceive + observe in ONE call: concepts, claims (mapped to B attributes), question/humour/warmth/low effort, dealbreaker hint, language, mood, notes about them and agenda hits (all with verbatim quotes) | mid, reasoning off, t=0 | see `conversation/perceive.js` (items that don't parse are dropped; non-verbatim quotes dropped) | `conversation/perceive.js` |
| `stanceCheck.js` | Only when the act plan says I must disagree: does the draft concede? | fast, reasoning off, t=0 | `{ concedes }` | `persona/checks.js` |
